PC Purifier

Minimum Requirements

  • OS: Windows 10 (64-bit) or newer
  • Processor: Intel Core i3 / AMD Ryzen 3 or equivalent
  • RAM: 4 GB
  • Storage: 100 MB available space
  • Display: 1280x720 resolution
  • Other: .NET 6.0 Runtime (included in installer)

Recommended

  • OS: Windows 11 (64-bit)
  • Processor: Intel Core i5 / AMD Ryzen 5 or better
  • RAM: 8 GB or more
  • Storage: 500 MB (for logs and reports)
  • Display: 1920x1080 resolution
  • Permissions: Administrator rights (for deep clean operations)

Supported Windows Versions

  • ✅ Windows 11 (all editions)
  • ✅ Windows 10 (version 1909 or newer)
  • ⚠️ Windows 8.1 (limited testing - may work but not officially supported)
  • ❌ Windows 7 and older (not supported)

The Forge (D&D Character Builder)

Minimum Requirements

  • OS: Windows 10 (64-bit) or newer
  • Processor: Intel Core i3 / AMD Ryzen 3
  • RAM: 4 GB
  • Storage: 200 MB
  • Display: 1280x720 resolution
  • Other: .NET 6.0 Runtime

Recommended (with AI Assistant)

  • OS: Windows 11 (64-bit)
  • Processor: Intel Core i7 / AMD Ryzen 7
  • RAM: 16 GB (for local AI models)
  • Storage: 5 GB (AI models can be large)
  • GPU: Nvidia RTX 3060 or better (for faster AI inference)
  • Display: 1920x1080 or higher

Status

The Forge is currently in development. Requirements may change before release.

Creative QR

The first release targets Windows PCs with a 64-bit Intel or AMD processor. Microsoft Store packaging and final compatibility checks are in progress; the Store listing will show the supported Windows versions when available.

  • No Creative QR account is required.
  • QR creation, previews and PNG exports work offline. Internet is needed to download the app and send optional feedback.
  • A configured Windows printer or Print to PDF destination is needed for printing.
  • Custom icons support PNG, JPG and WebP files up to 10 MB and 25 megapixels.
  • Large card exports and saved PNGs use additional memory and disk space. Final download size will be listed with the Store release.

Master Generator

Current Public Version

Master Generator is available for Windows through Microsoft Store, Android through Google Play, and iPhone and iPad through the Apple App Store. Check the store listing for your device requirements.

Storage

Campaign vaults are stored locally on your computer. Export a JSON backup if you want to move campaigns to another device.

Internet

Core generators and campaign vaults are local-first. TreV, Google Play, and downloadable map or magic item image packs use internet access when selected.

Windows Build

Install the Windows app through Microsoft Store using the link on the Master Generator page. The store lists the current Windows requirements and handles app updates.

General Notes

Runtime Dependencies

Current public downloads are portable ZIPs where practical. Extract the ZIP and run the app EXE inside. Some future installer builds may include their required runtimes directly.

Internet Connection

Some tools work offline after download. Optional cloud or AI features in other tools only use the endpoint you configure.

Antivirus Compatibility

Our releases are designed to work with major antivirus software. Windows Defender SmartScreen may still warn when a download is new or not commonly downloaded yet.

Administrator Rights

Some features (like PC Purifier's Deep Clean or system optimizations) may require administrator privileges. You'll be prompted when needed.
