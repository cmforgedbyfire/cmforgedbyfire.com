Before You Contact Support

Include the Basics

Name the platform, app version, tool, source format, expected result, and what happened. Never send passwords, payment information, or unrelated private files.

Preserve the Original

Creative Image Tools writes new copies. If an output is not useful, remove that copy and keep the original while the issue is investigated.

Unavailable Source

If a selected file becomes unavailable, remove it from the queue and choose it again so the operating system can renew access.

Format Support

Windows conversion outputs JPEG, PNG, BMP, and TIFF. Android outputs JPEG, PNG, and WebP; lossless WebP requires Android 11 or later.

Send Feedback

In Windows, choose Feedback in the lower sidebar. On Android, open About and use Send feedback. Select a category, enter a message, optionally enter a reply email, and press the send button. If delivery cannot be confirmed, your draft stays in the open form so you can try again.

The app sends only the message, category, optional reply email, and app version. It does not attach images, filenames, folders, queue contents, settings, or device and installation identifiers.

You can also email forgedbyfiresoftware@gmail.com or use the company's support form.

Local Data and Privacy Requests

Creative Image Tools has no user account to delete. Source images and completed outputs remain wherever you keep them and can be deleted with your normal device storage tools. Local preferences and recoverable task state can be removed by clearing the app's data or uninstalling according to the operating system's behavior. Uninstalling does not delete images stored in user-controlled locations.

Clearing local data does not remove feedback already submitted. To request access, correction, deletion, or de-identification of identifiable feedback, email forgedbyfiresoftware@gmail.com. Include the approximate submission date and the reply email or enough of the message to locate it. Anonymous feedback may be difficult or impossible to identify.

We aim to handle verifiable privacy requests within 30 days. See the full retention and control details.

Current Availability

The Windows and Android apps are in development. The Windows preview is being prepared for Microsoft Store submission and is not yet publicly available.
